# 🥽 Augmented Reality Content Creator

System that generates contextual content for AR applications.

**Author:** Pranay M

## 🌟 Features

| Module | Description |
|--------|-------------|
| **Context Analyzer** | Analyze AR context |
| **Content Generator** | Generate AR content |
| **Object Annotator** | Create annotations |
| **Scene Describer** | Describe scenes |
| **Interaction Designer** | Design interactions |
| **Audio Scripter** | Create audio scripts |
| **Spatial Planner** | Plan spatial layout |
| **Animation Director** | Direct animations |
| **UX Optimizer** | Optimize experience |
| **Export Manager** | Export projects |

## 🚀 Quick Start

```bash
ollama pull llama3.2 && ollama serve
pip install -r requirements.txt
python main.py
```
